## 排查登录注册失败问题

### 项目背景
粤港甄选跨境智汇AI系统 - Spring Cloud 微服务架构
- 调用链路：前端 → Gateway(8080) → Auth(8081) / User(8082) / System(8083)
- 基础设施：MySQL/Redis/Nacos 跑在虚拟机 192.168.153.128 的 Docker 容器中

### 根本原因
**MySQL 数据库应用用户的密码不匹配**

MySQL（Docker 容器 ygh-mysql）里 `ygh_auth_app` 用户存在两个条目：
- `ygh_auth_app@%`（任意主机）
- `ygh_auth_app@192.168.153.1`（具体主机）

具体主机条目的密码与 `start-auth.ps1` 配置的 `YGH_AUTH_DB_APP_PASSWORD=123456` 不一致。

错误日志样本（`ygh-platform/ygh-auth-service/logs/ygh-auth-service.log`）：
```
java.sql.SQLException: Access denied for user 'ygh_auth_app'@'192.168.153.1' (using password: YES)
```

### 修复
通过 SSH（paramiko，因为 Windows 上没 sshpass）连接到 192.168.153.128，用 docker exec MySQL 重置密码：
```sql
ALTER USER 'ygh_auth_app'@'192.168.153.1' IDENTIFIED BY '123456';
ALTER USER 'ygh_auth_app'@'%' IDENTIFIED BY '123456';
ALTER USER 'ygh_user_app'@'192.168.153.1' IDENTIFIED BY '123456';
ALTER USER 'ygh_user_app'@'%' IDENTIFIED BY '123456';
ALTER USER 'ygh_system_app'@'192.168.153.1' IDENTIFIED BY '123456';
ALTER USER 'ygh_system_app'@'%' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
```

### 验证结果
- ✅ 注册成功（直连 8081 + 正确 challenge ID）
- ✅ 通过网关 8080 登录成功，返回 JWT
- ⚠️ 直连 8081 登录失败（设计如此，HMAC 签名验证）

### 重要设计细节
- 密码策略：最少 15 字符，最多 128 字符（PasswordPolicy.MIN_LENGTH=15）
- 验证码：6 位字符（来自 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`）
- 验证码在 Redis 存储为 SHA-256 哈希，无法直接读取
- 登录注册必须通过 Gateway 8180（或 8080）调用，因为 Auth 服务开启 JWT 模式后需要 HMAC 签名

## 注册可登录账号并重置密码

### 现象
验证码连续几次得 400 VALIDATION_ERROR，但奇怪的是数据库里 `ygh_admin` 账户还是被创建了（来源不明的请求，可能是用户前端/浏览器在持续重试）。验证登录时，密码不是我设的，登录 401。

### 解决：直接改数据库里的 Argon2 哈希
走 API 注册可能因为某些限流/快照竞争出问题，干脆直接生成 Argon2 哈希塞到 `auth_credential.password_hash` 里。

Paramiko 注意事项：含 `$` 的 Argon2 字符串通过 bash 会被展开。用 `docker exec -i mysql ...` + stdin 推 SQL 才能安全传入 `$$` 字符。

Argon2 参数（对齐 `Argon2PasswordHasher.owaspMinimum()` + Java BouncyCastle）：
- 算法: ARGON2ID
- salt: 16 字节
- hash: 32 字节
- memory: 19456 KiB
- iterations: 2
- parallelism: 1
- 编码格式：`$argon2id$v=19$m=19456,t=2,p=1$<salt_b64_nopad>$<hash_b64_nopad>`

Python 生成（用 `argon2-cffi` 的 `hash_secret_raw`）：
```python
from argon2.low_level import hash_secret_raw, Type
import os, base64
salt = os.urandom(16)
h = hash_secret_raw(password.encode('utf-8'), salt, time_cost=2, memory_cost=19456, parallelism=1, hash_len=32, type=Type.ID)
encoded = f"$argon2id$v=19$m=19456,t=2,p=1${base64.b64encode(salt).decode().rstrip('=')}${base64.b64encode(h).decode().rstrip('=')}"
```
